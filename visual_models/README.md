LLM Vision Shim and Benchmark (minimal stubs)

This folder contains a minimal FastAPI shim and benchmark runner used for Week 1:

- service/app.py: a tiny FastAPI server that provides a /predict endpoint. It returns deterministic placeholder responses based on image filename (login*, dashboard*, etc.).
- requirements.txt: python dependencies for the shim.
- Dockerfile: simple container to run the shim (example uses port 8001).
- models.json: list of model stubs and endpoints used by the benchmark runner.
- benchmark_runner.py: script that posts images and their accessibility-tree specs to the model endpoints and stores raw JSON outputs under visual/benchmark/results.

How to run locally (example):

1. Start one or more shim instances (in separate shells) for each model stub:
   python visual_models/service/app.py  # runs on 8001 by default
   # to run on other ports, set PORT env var, e.g. PORT=8002 python app.py

2. Ensure visual dataset exists: visual/dataset/initial (generated by flaui-runner).

3. Run the benchmark runner:
   python visual_models/benchmark_runner.py

Results are written to visual/benchmark/results/<model-name>/*.json

These are stubs for experimentation. Replace service/app.py with a real model server (BLIP-2, LLaVA, MiniGPT-4 variants) behind the same /predict contract to run real benchmarks.
